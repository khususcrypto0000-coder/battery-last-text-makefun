One-line entry for the make.fun bounty "The Battery's Last Text to Its Charger": a dying phone battery texts its charger with a last-minute correction — it was never the phone's battery at all. A mistaken-identity twist, told in a casual lowercase texting voice, with the punchline landing in the final words.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (UTF-8, one line, 195 characters) and verifies it by reading the file back byte-for-byte.
